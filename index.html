How to use
1. GF / DMを切り替える

画面上部のGF / DMボタンで表示するスキルを切り替えます。

2. スコアを登録する

「登録」→「＋登録」から曲名・パート・達成率・フルコンを入力します。GFでは譜面オプションも登録できます。

3. スキル対象を同期する

MENU →「スキル対象同期」から、GITADORA公式ページからスキル対象をまとめて取得できます。

4. ライバルを登録する

ユーザーリストからGF / DMそれぞれ最大10人まで登録と解除ができます。「ライバル管理」では登録しているユーザーが一覧で確認できます。

5. 登録曲詳細を見る

登録曲をタップするとライバルとの達成率比較、歴代の自己ベスト、GFでは譜面オプションの使用割合を確認できます。

6. SNSへ共有する

MENU →「スキル画像共有」から現在のGF / DMスキル対象画像を作成し、端末の共有メニューからXやInstagramなどへ送れます。
